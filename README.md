## 🧠 Overview

This repository is designed for learning and revision. Each file focuses on a single problem or concept and can be executed independently with Node.js. The solutions are intentionally simple and educational, making them ideal for beginners and anyone revisiting the fundamentals.

## 🛠️ Topics Covered

- 📚 Arrays and strings
- 🔍 Searching and sorting algorithms
- 🔗 Linked list operations
- ♻️ Recursion and pattern-based problems
- 🔢 Mathematical and number-based challenges
- 📝 Common interview preparation questions

## ▶️ Getting Started

### ✅ Prerequisites

- 🟢 Node.js installed on your machine

### ▶️ Run a Solution

Use Node.js to execute any file:

```bash
node "Best Time to sell Stocks.js"
```

If a file name contains spaces, wrap it in quotes as shown above.

## 🧭 How to Use This Repository

1. 🎯 Choose a topic you want to practice.
2. 📂 Open the corresponding JavaScript file.
3. 🧠 Read the logic and understand the approach.
4. ▶️ Run the file with Node.js.
5. 🔁 Modify the input or try a similar example to test your understanding.
